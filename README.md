# Home Binder entry page

A standalone GitHub Pages entry point for the private Home Binder application.

The live application and database stay at https://home-binder-pages.hwttpccppg.chatgpt.site/. GitHub Pages serves only this public entry page. No credentials, invitations, household records, or personal reference documents are included in this repository.

Publish from the root of this repository's `main` branch using GitHub Pages. The repository is independent of all Dojo projects and uses no custom domain or existing Dojo deployment settings.

Cloud access is controlled on the application host. Each authorized person signs in using their own ChatGPT account; page data is keyed to that identity. Access invitations are managed on the private site, not here.
